## 这是什么？

简单说，这就是我自己学 Codex 的笔记站。

Codex 是 OpenAI 做的一个 AI 编程助手，能帮你写代码、改 bug、跑命令、整理资料。但官方文档写得太"官方"了，读起来像天书，我看不太下去，所以决定自己用大白话重新整理一遍。

如果你也觉得官方文档让人头疼，那这里可能适合你。

## 我是谁？

一个普通的后端开发，平时写 Java、搞 IoT，跟 Codex 摸索了大半年。不是大牛，就是把自己踩过的坑和搞明白的东西记下来。

如果你觉得有用，拿去用就行。如果觉得写得不对，那大概率是我理解有误，欢迎指正。
