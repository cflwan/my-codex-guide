# 理解费用与上下文

## 先搞明白钱的事

Codex 不是无限免费的。它按 token 计费。

## 什么是 token

token 就是 AI 处理文本的最小单位。一个中文字大约 1-2 个 token，一个英文单词大约 1 个 token。

你每次跟 Codex 对话，都消耗 token：
- **输入 token**：你说的话 + 项目文件内容 + 系统提示
- **输出 token**：Codex 回复的内容 + 它写的代码

## 怎么计费

::: tip 官方为准
具体价格以 [OpenAI 官方定价](https://openai.com/api/pricing/) 为准，可能随时调整。
:::

大致规律：
- 输入比输出便宜
- 大模型比小模型贵
- 缓存命中比不命中便宜

## 什么是上下文

上下文就是 Codex "记得"的内容。

每次对话，Codex 会把之前的对话历史 + 当前消息一起发给模型。对话越长，上下文越大，token 消耗越多。

## 怎么省钱

| 省钱技巧 | 说明 |
| --- | --- |
| 用小模型 | 简单任务用 o4-mini，复杂任务才用大模型 |
| 别太长对话 | 一个任务一个线程，别在一个线程里聊太多 |
| 用 AGENTS.md | 把常用规则写进去，不用每次重复说 |
| 善用缓存 | 相同的上下文会缓存，别频繁改上下文 |
| 非交互模式 | `codex exec` 比交互模式省 token |

## 我的经验

::: tip
一个月用 Plus 订阅（$20）对大多数人够用。如果你发现自己经常超限，再考虑 Pro 或第三方 API。
:::
