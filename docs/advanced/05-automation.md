# Automation（自动化）

## 啥是自动化

简单说：你设一个规则，Codex 在特定条件下自动执行任务。

比如：
- 每天早上自动跑测试
- 有新 commit 时自动 Code Review
- CI 失败时自动修复

## 怎么配

::: tip 官方为准
自动化功能以 [Codex 官方文档](https://developers.openai.com/codex/) 为准。
:::

基本步骤：
1. 在 Codex 里找到 Automation 设置
2. 设定触发条件（定时、事件、手动）
3. 写任务描述
4. 设定权限边界

## 实用场景

### 场景一：每天跑测试

```
触发：每天 8:00
任务：跑 mvn test，如果有失败的测试，尝试修复
权限：只读 + 修改 test 目录
```

### 场景二：CI 失败自动修

```
触发：GitHub Actions 失败
任务：读 CI 日志，定位问题，修代码，提 PR
权限：只修改 src/ 目录
```

## 注意事项

- 自动化任务要设好权限边界，别让它干太猛
- 先手动跑通，再设自动化
- 设个通知，知道它干了啥
