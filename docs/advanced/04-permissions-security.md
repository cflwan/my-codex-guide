# 权限管理

## 为什么要管权限

Codex 能读文件、写文件、跑命令、连网络。如果不加限制，它可能：
- 误删重要文件
- 执行危险命令
- 把代码上传到不该传的地方

权限管理就是给 Codex 划红线。

## 核心概念

| 概念 | 大白话 |
| --- | --- |
| 沙盒 | Codex 的"活动区域"，出了这个区域就要审批 |
| 审批 | Codex 要做敏感操作时，问你行不行 |
| Auto-Review | 自动审查 Codex 的改动 |

## 几个关键设置

### 文件权限

- Codex 能读哪些目录
- Codex 能写哪些目录
- 哪些目录绝对不能碰

### 命令权限

- 哪些命令可以自动执行
- 哪些命令需要审批
- 哪些命令禁止执行

### 网络权限

- 能不能联网
- 能连哪些域名

## 我的建议

::: tip 新手建议
刚开始用的时候，默认设置就行。Codex 的默认安全策略对新手够用。

等你熟了，再根据需要调整。
:::
