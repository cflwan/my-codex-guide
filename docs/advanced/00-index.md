# 进阶教程

## 这个板块是给谁的

你已经能基本使用 Codex 了，想更深入地理解和控制它。

这些内容不是必须的，但能让你的效率翻倍。

## 推荐顺序

### 1. [费用与上下文](./01-cost-context.md)
先搞明白 Codex 怎么计费，别花冤枉钱。

### 2. [AGENTS.md](./02-agents-md.md)
让 Codex 记住你的项目规则，不用每次重复说。

### 3. [Skills 和 Plugins](./03-skills-plugins-mcp.md)
扩展 Codex 的能力，让它能干更多事。

### 4. [权限管理](./04-permissions-security.md)
控制 Codex 能干什么不能干什么。

### 5. [自动化](./05-automation.md)
让 Codex 定时帮你干活。

### 6. [Hooks](./06-hooks.md)
在 Codex 执行过程中插入你的逻辑。

### 7. [沙盒与审批](./07-sandbox-approvals.md)
安全边界，别让 AI 瞎搞。

### 8. [自动线程管理](./08-thread-management.md)
多任务管理，一个线程干一件事。

### 9. [config.toml](./09-config-toml.md)
核心配置文件详解。

### 10. [团队实践](./10-team-playbook.md)
带着团队一起用 Codex。

### 11. [排障手册](./11-troubleshooting.md)
遇到问题先来这查。

## 学完能做到什么

- 知道 Codex 怎么计费，能控制成本
- 会写 AGENTS.md，让 Codex 自动遵守项目规则
- 会用 Skills 扩展能力
- 会配安全边界，不怕 AI 乱来
- 能搞自动化，让 Codex 定时干活
- 能带团队用

## 我的建议

::: tip 别一次全学
这些内容不用一次学完。用到哪个学哪个，自然就都会了。
:::
