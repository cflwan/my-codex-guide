# 排障手册

## 常见问题速查

### 安装相关

| 问题 | 解决 |
| --- | --- |
| 装不上 | 检查 Node 版本 >= 22 |
| 权限不够 | `sudo npm install -g` |
| 网络超时 | 配代理或换 npm 镜像 |

### 登录相关

| 问题 | 解决 |
| --- | --- |
| 登录跳转不了 | 检查网络/代理 |
| 提示无权限 | 检查是否订阅了 Plus/Pro |
| API Key 无效 | 检查 Key 是否正确、是否过期 |

### 使用相关

| 问题 | 解决 |
| --- | --- |
| Codex 不改文件 | 检查工作目录、沙盒设置 |
| 改了但不生效 | 检查是否需要重启服务 |
| 对话太长变慢 | 开新线程，别一个线程聊太多 |
| 回答跑题 | 重新描述任务，写清楚目标 |

### 性能相关

| 问题 | 解决 |
| --- | --- |
| 响应慢 | 换小模型（o4-mini） |
| token 不够用 | 升级计划或用第三方 API |
| 大项目卡 | 只给 Codex 相关目录，别给整个仓库 |

## 还是搞不定？
