# 自动线程管理

## 啥是线程

在 Codex 里，一次对话就是一个线程。每个线程有独立的上下文。

你可以同时开多个线程，每个干不同的事。

## 为什么有用

- 一个线程改代码
- 另一个线程写文档
- 还有一个跑测试

互不干扰，不用等一个完了再开始下一个。

## 怎么管理

| 操作 | 干啥 |
| --- | --- |
| 新建线程 | 开一个新对话 |
| 继续 | 继续之前的线程 |
| 分叉 | 从某个点分出一条新路线 |
| 移交 | 把线程交给另一个 agent |
| 归档 | 不用了但不删 |

## 我的经验

::: tip
一个任务一个线程。别在一个线程里塞太多不同的任务，上下文会混乱。

任务做完了就归档，保持线程列表清爽。
:::
