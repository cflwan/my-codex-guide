# 学习路线

## 先说结论

别按顺序读，按需求读。

Codex 这东西，你硬从头到尾学一遍意义不大。它就是个工具，**用到啥学啥**最有效率。下面是我建议的路线，你挑自己需要的看就行。

## 路线一：第一次用（推荐大多数人）

如果你还没装过 Codex，从这里开始：

1. [Codex 是什么](/start/01-what-is-codex.md) - 先搞明白这玩意到底是个啥
2. [桌面 App 安装](/start/02-app-installation.md) - 把软件装上
3. [搞个账号](/start/03-account-plan.md) - 登录搞定才能用
4. [了解基本界面](/start/05-app-overview.md) - 知道每个按钮干嘛的
5. [跑第一个任务](/start/06-first-task.md) - **重点来了，这一步跑通你就入门了**
6. [怎么描述任务](/start/07-task-design.md) - 学会跟 AI 说话，这比啥技巧都重要

完事。到这一步你已经能干活了。

## 路线二：想用 CLI 在终端里搞

如果你是终端党，不喜欢开 GUI：

1. [CLI 安装](/start/10-cli-installation.md)
2. [第一次跑 CLI](/start/11-cli-first-run.md)
3. [CLI 选项速查](/start/12-cli-options.md)

## 路线三：用熟了想玩花的

到这一步说明你已经能基本使用了，想更深入：

1. [费用与上下文](/advanced/01-cost-context.md) - 先搞明白怎么计费，别花冤枉钱
2. [AGENTS.md](/advanced/02-agents-md.md) - 让 Codex 记住你的项目规则
3. [Skills 和 Plugins](/advanced/03-skills-plugins-mcp.md) - 扩展能力
4. [沙盒与审批](/advanced/07-sandbox-approvals.md) - 安全问题，别让 AI 瞎搞
5. [config.toml](/advanced/09-config-toml.md) - 配置文件详解
6. [自动化](/advanced/05-automation.md) - 让 Codex 定时帮你干活
7. [Hooks](/advanced/06-hooks.md) - 在执行过程中插入自定义逻辑

## 路线四：看看别人怎么用的

[实战案例库](/recipes/) - 照着别人的案例抄一遍，比看文档学得快。

## 路线五：团队用 Codex

如果你要带着团队一起用：

1. [团队实践](/advanced/10-team-playbook.md)
2. [AGENTS.md](/advanced/02-agents-md.md) - 团队规则必须写下来
3. [权限管理](/advanced/04-permissions-security.md)
4. [排障手册](/advanced/11-troubleshooting.md)

## 一个建议

::: tip 我的经验
用 Codex 最好的学法不是看文档，而是**带着真实问题去用**。文档看十遍不如自己跑一次。

遇到搞不定的问题再回来查，效率最高。
:::
