# 桌面 App 下载与安装

## 去哪下

去 OpenAI 官网下载：[https://openai.com/codex/](https://openai.com/codex/)

找到下载按钮，选你的系统（Mac 或 Windows），下载安装就行。

::: tip 官方优先
下载地址和系统要求可能随时变，以 [OpenAI Codex 官网](https://openai.com/codex/) 为准。
:::

## Mac 安装

1. 下载 `.dmg` 文件
2. 双击打开
3. 把 Codex 拖进 Applications 文件夹
4. 打开 Applications，双击 Codex 启动

::: warning Mac 安全提示
第一次打开可能会提示"无法验证开发者"。
解决：系统设置 -> 隐私与安全性 -> 点"仍要打开"。
:::

## Windows 安装

1. 下载 `.exe` 安装包
2. 双击运行
3. 跟着安装向导走
4. 安装完从开始菜单启动

## 安装完第一步

打开 App，它会让你登录。这时候你需要一个 ChatGPT 账号。

如果还没有，下一步看 [搞个账号](./03-account-plan.md)。

## 常见问题

**Q：装不上？**
检查系统版本。Mac 需要 macOS 13 以上，Windows 需要 Windows 10 以上。

**Q：打开就闪退？**
试试关掉杀毒软件再开。还不行就重新下载安装包。

**Q：网络连不上？**
国内网络可能需要特殊处理，或者用第三方 API（下一步会讲）。
