# 搞个账号

## 你需要什么

Codex 不是独立的产品，它挂在 ChatGPT 下面。所以你要有一个 ChatGPT 账号，并且订阅了付费计划。

## Plus 还是 Pro？

| 计划 | 价格 | 适合谁 |
| --- | --- | --- |
| ChatGPT Plus | $20/月 | 个人用户，轻度使用 |
| ChatGPT Pro | $200/月 | 重度用户，几乎无限制 |

::: tip 我的建议
先别急着买 Pro。Plus 对大多数人够用了，等你用多了发现不够再升级也不迟。
:::

## 怎么订阅

1. 打开 [ChatGPT 官网](https://chatgpt.com/)
2. 注册 / 登录
3. 点左下角你的头像 -> Settings
4. 选 Subscription / 订阅
5. 选 Plus，绑定信用卡
6. 付款

::: warning 国内用户注意
国内信用卡可能支付不了。可以试试：
- 万事达/Visa 双币卡
- 虚拟信用卡（如 Depay）
- 找代充服务（注意甄别，有风险）
:::

## 第三方 API 替代方案

如果你实在搞不定 ChatGPT 官方订阅，还有一条路：**第三方 API**。

简单说就是不用 ChatGPT 官方账号，用第三方平台提供的 API Key 来驱动 Codex。下一页 [连接第三方 API](./04-third-party-api.md) 会详细讲。

## 登录 Codex

账号搞定后：

1. 打开 Codex 桌面 App
2. 会弹出登录窗口，用 ChatGPT 账号登录
3. 登录成功后会自动跳回 App

搞定，现在你可以用 Codex 了。
