# 连接第三方 API

## 什么时候需要这个？

- 国内信用卡付不了 ChatGPT 订阅
- 想用更便宜的方案
- 公司有自己的 API 中转

## 原理

Codex 底层调的是 OpenAI 的模型。第三方平台做的事情就是：帮你搞定 API 访问，你用他们的 Key 就行。

## 怎么配

::: tip 官方为准
第三方 API 的配置方式可能随版本变化，具体操作以 [Codex 官方文档](https://developers.openai.com/codex/) 和你选的 API 平台说明为准。
:::

基本步骤：

1. **选一个 API 平台**：国内有不少 API 中转服务，选一个靠谱的
2. **注册并充值**：拿到 API Key
3. **在 Codex 里配置**：
   - 打开 Codex 设置
   - 找到 API / Provider 相关设置
   - 填入你的 API Key 和 Base URL
4. **测试连接**：发一个简单任务试试能不能通

## 选平台注意啥

- **价格**：按 token 计费，对比各平台单价
- **稳定性**：看看别人评价，别选跑路平台
- **支持模型**：确认有 Codex 需要的模型（如 o3、o4-mini 等）
- **隐私**：看看隐私政策，别选会存你代码的

::: warning 风险提示
第三方 API 平台鱼龙混杂。你的代码会经过它们的服务器。
- 敏感项目别用第三方
- 别把密钥、生产数据传过去
- 充值别充太多，用多少充多少
:::
