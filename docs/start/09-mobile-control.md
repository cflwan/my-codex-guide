# 用手机远程操控 Codex

## 啥意思？

你在电脑上让 Codex 跑一个任务（比如改代码、跑测试），然后你可以出门买杯咖啡，用手机查看进度、回复审批。

## 前提条件

- 电脑上 Codex 桌面 App 在运行
- 手机装了 ChatGPT App
- 电脑和手机用同一个 ChatGPT 账号

## 怎么连

::: tip 官方为准
手机端协同功能可能随版本变化，具体操作以 [OpenAI 官方说明](https://help.openai.com/en/articles/11369540-codex-in-chatgpt) 为准。
:::

1. 电脑上打开 Codex 桌面 App，开始一个任务
2. 手机打开 ChatGPT App
3. 在 ChatGPT 里找到 Codex 入口
4. 可以看到正在运行的任务
5. 如果 Codex 需要审批（比如执行命令），手机上点同意/拒绝

## 能干什么

- **查看任务状态**：跑到哪了
- **审批操作**：Codex 要执行命令时，手机上同意或拒绝
- **继续对话**：追加指令
- **查看结果**：看 Codex 的回复

## 限制

- 手机不能直接改文件
- 需要网络畅通
- 电脑不能关机/休眠
- 功能取决于你的账号计划

## 实际场景

**场景一**：你让 Codex 跑一个大测试，然后去开会。开会时手机收到通知"测试失败"，你直接手机回复"看看失败日志，修一下"。

**场景二**：你让 Codex 重构代码，出门吃饭。手机上审批每个文件修改。
