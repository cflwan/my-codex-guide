# 快速上手

## 这个板块是给谁的？

第一次用 Codex 的人。

不管你是开发还是非开发，只要之前没用过，就从这里开始。跟着下面几步走，半小时内你能让 Codex 帮你干第一件活。

如果你不是开发者，或者不想折腾命令行，用桌面 App 就够了：

2. [桌面 App 下载安装](./02-app-installation.md) - 装软件
3. [搞个账号](./03-account-plan.md) - 登录

6. [跑第一个任务](./06-first-task.md) - **最关键的一步**
7. [怎么描述任务](./07-task-design.md) - 跟 AI 说话的艺术
8. [验证结果](./08-task-execution.md) - 检查 AI 干的活

## 学完能做到什么

- 知道 Codex 是啥，不是啥
- 装好软件、登录账号
- 能给 Codex 一个文件夹让它干活
- 能写清楚你想让它干啥
- 能检查它干得对不对
- 知道什么时候该信它，什么时候不能信
