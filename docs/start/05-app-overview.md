# 了解 Codex 基本组成

## 打开 App 你会看到啥

别被界面吓到，其实就那么几个区域：

## 核心区域

### 1. 对话区（中间最大那块）

这是你跟 Codex 说话的地方。跟聊天软件差不多，你打字，它回复。

区别在于：它回复的不只是文字，还会告诉你它做了什么操作（改了哪个文件、跑了什么命令）。

### 2. 文件区（左边或上方）

这里显示你交给 Codex 的工作目录。你能看到项目文件列表，知道 Codex 在哪个文件夹里干活。

### 3. 任务/线程列表（侧边栏）

每次对话就是一个"线程"。你可以同时开多个线程，互不干扰。适合同时处理多个任务。

### 4. 设置区

配置 Codex 的行为：权限、模型、API、自动化等。

## 你需要知道的几个概念

| 概念 | 大白话解释 |
| --- | --- |
| Thread（线程） | 一次对话。不同线程之间独立，不会串。 |
| Worktree（工作树） | Codex 干活的文件夹。可以隔离不同任务。 |
| Skill（技能） | Codex 会的东西。可以扩展。 |
| Sandbox（沙盒） | 安全围栏。限制 Codex 能碰什么不能碰什么。 |
| AGENTS.md | 项目规则文件。告诉 Codex 你的项目有啥规矩。 |

## 最重要的一个按钮

**Send（发送）**。

别的先不用管，知道怎么发消息给 Codex 就行。剩下的边用边学。

## 第一次用别紧张

- Codex 不会主动搞坏你的文件（默认安全模式）
- 你可以随时撤销它的操作
- 它问你"要不要执行"的时候，看清楚再点同意
