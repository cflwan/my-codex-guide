# Codex 是什么

## 一句话版本

Codex 是 OpenAI 做的 AI 编程助手，能帮你写代码、改 bug、跑命令、整理资料。

## 多说几句

你可能用过 ChatGPT，跟它聊天问问题。Codex 可以理解为 ChatGPT 的"能干活版"——它不只是跟你聊天，它能真的动手：

- **读你的项目文件**，知道你的代码长什么样
- **写代码**，直接帮你创建或修改文件
- **跑命令**，执行终端命令并看结果
- **调用工具**，操作浏览器、读设计稿、连数据库

说白了，ChatGPT 是你的顾问，Codex 是你的员工。

## 它有几种形态

Codex 不是一个单独的东西，它有好几个入口：

| 入口 | 简单理解 | 适合谁 |
| --- | --- | --- |
| 桌面 App | 装在电脑上的软件，有界面 | 大多数人，推荐从这里开始 |
| CLI | 终端里敲命令 | 开发者，终端党 |
| Cloud / Web | 浏览器里用，跑在云端 | 需要跑长任务的人 |
| IDE 插件 | 集成到 VS Code 里 | 习惯在编辑器里写代码的人 |
| ChatGPT 里的 Codex | 手机 App 里也能用 | 想用手机跟进任务的人 |

## 新手怎么选？

**别纠结，先用桌面 App。**

桌面 App 有界面、有按钮、能看到文件，最直观。等你用熟了，再试试 CLI 或 IDE 插件。

## 它不是什么

- 不是全自动的——你得告诉它干啥，它不会自己主动干活（除非你设了自动化）
- 不是万能的——它会犯错，尤其是复杂逻辑，你得检查
- 不是免费的——需要 ChatGPT Plus 或 Pro 订阅，或者用第三方 API
