# 用 Codex 完成第一个任务

## 别想太多，先跑通

第一次用别搞复杂的。咱们来个最简单的：让 Codex 帮你创建一个文件。

## 准备工作

1. 新建一个空文件夹，比如 `~/Desktop/codex-test`
2. 打开 Codex 桌面 App
3. 把这个文件夹设为工作目录（Open Folder -> 选你刚建的文件夹）

## 第一个任务：写个自我介绍页面

在对话框里输入：

```
帮我创建一个 index.html 文件，内容是一个简单的自我介绍页面。
要求：
- 纯 HTML，不需要 CSS
- 标题写"你好，我是 Codex 的用户"
- 下方写一段话介绍你自己
- 底部写上今天的日期
```

点发送。

## 会发生什么

Codex 会：
1. 理解你的需求
2. 创建 `index.html` 文件
3. 写入内容
4. 告诉你它做了什么

你会在对话区看到它的回复，文件区看到新文件。

## 验证结果

1. 打开 `~/Desktop/codex-test/index.html`
2. 双击用浏览器打开
3. 看看页面长啥样

如果看到你的自我介绍页面，恭喜，你的第一个 Codex 任务成功了！

## 如果出错了

**Codex 没创建文件？**
- 检查工作目录是不是选对了
- 检查是不是在"只读"模式（沙盒限制）

**文件创建了但内容不对？**
- 直接跟它说"内容不对，xxx 地方改一下"
- Codex 支持连续对话，不用重新开始

## 第二个任务：让它改代码

现在试试让它修改文件：

```
把 index.html 加上 CSS 样式：
- 背景改成深色
- 文字改成白色
- 标题居中
- 字体用 sans-serif
```

发送，看看它怎么改。

## 你刚学到了什么

- 怎么给 Codex 一个文件夹
- 怎么描述任务
- 怎么检查结果
- 怎么让它修改

这就是 Codex 的基本工作流程：**描述 -> 执行 -> 检查 -> 修改**。
