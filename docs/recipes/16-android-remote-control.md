# 用安卓手机远程操控 Codex

## 这案例干啥的

就是你在外面,只有个安卓手机,但想给家里的 Codex 下个任务--比如"帮我跑下昨晚那个脚本""看下服务器日志"。

相当于用手机远程遥控你的 AI。

## 啥时候用

- 通勤路上想到个工作,想让 Codex 先干着
- 出差时需要处理家里/公司电脑上的事
- 半夜报警,手机先让 AI 看一眼啥情况
- 不方便开电脑,但有手机

## 准备工作

- 电脑开着机,Codex 在跑(或者能被远程唤醒)
- 安卓手机装好能连 Codex 的 app(或者用 Termux、SSH 之类的)
- 电脑和手机能互通(同一局域网,或者用 frp/Tailscale 打通)
- 配好认证,别让外人随便连

## 怎么搞

### 第一步:打通连接

选一种方式让手机能"够到"电脑上的 Codex:
- Tailscale/ZeroTier 组网(推荐,简单安全)
- frp 内网穿透
- Termux + SSH 到电脑

### 第二步:手机上发指令

用对应 app 连到电脑,直接发指令给 Codex:

> 帮我看下 /var/log/myapp/error.log 最近的报错,如果有 NPE 就把堆栈和上下文发给我手机(用飞书机器人通知)。

### 第三步:Codex 干活

电脑上的 Codex 接到指令,该读日志读日志,该跑脚本跑脚本。

### 第四步:结果回传

让 Codex 把结果发到你手机能收到的地方:
- 飞书/钉钉机器人推消息
- 邮件
- 手机上的某个 app 通知

### 第五步:确认/继续

你手机上收到结果,如果有后续操作,继续发指令:

> 那个 NPE 是 UserService.java:45 的,帮我加个判空,改完提交个 commit,别部署。

## 验证结果

- 手机能连上电脑上的 Codex(指令能发出去)
- Codex 能执行指令(看电脑端日志确认)
- 结果能回传到手机(你收到了通知)
- 延迟可接受(几秒内响应,不是卡几分钟)

## 注意事项

::: tip
务必配好认证(密钥、token)。手机能连,意味着别人理论上也能连。别用默认密码,别开公网端口。
:::

::: warning
手机远程操作时,AI 的"破坏性"操作(删文件、重启服务、改生产配置)一定要二次确认。手机上看信息不全,容易误判。
:::

## 我的经验

我固定用 Tailscale 组网,手机和电脑都在同一个虚拟网络里,连接稳定又安全。手机上用 Termux SSH 到电脑,直接给 Codex 发指令。

我设了个"快捷指令面板"--常用操作(查日志、跑测试、看 CI 状态)做成一键按钮,不用每次敲长命令。
