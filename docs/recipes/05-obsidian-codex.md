# 在 Obsidian 中用 Codex 生成配图

## 这案例干啥的

就是你在 Obsidian 里写笔记,写到一半发现"这里配张图就好了",直接让 Codex 帮你生成一张,插到笔记里。

不用切出去找图、存图、再贴回来,边写边出图。

## 啥时候用

- 写技术笔记,需要个流程图或示意图
- 做读书笔记,想配张概念图
- 写日报周报,想要个好看的封面
- 整理知识库,给每篇笔记配个特色图

## 准备工作

- Obsidian 装好,能正常用
- Codex CLI 能调用,最好配置成能访问 Obsidian 目录
- 笔记里知道哪儿需要配图
- 心里有个图的大概样子

## 怎么搞

### 第一步:在笔记里标记位置

在你需要配图的地方写个占位:

```markdown
这里需要一张系统架构示意图。
<!-- 配图:系统架构图,展示前端、后端、数据库三层 -->
```

### 第二步:调用 Codex

在终端里进到 Obsidian vault 目录,跟 Codex 说:

> 扫一下我这个笔记(test.md),看到有"配图"标记的地方,帮我生成对应的图片,存到 attachments/ 目录,然后把 markdown 里的图片引用补上。

### 第三步:AI 干活

Codex 会:
1. 读笔记,找到所有配图标记
2. 根据描述生成图片
3. 把图片存到指定目录
4. 在笔记里插入 `![](attachments/xxx.png)` 引用

### 第四步:回 Obsidian 看

切回 Obsidian,图片就显示出来了。不满意就跟 AI 说哪张要重出。

## 验证结果

- 笔记里出现了图片引用语法
- attachments/ 目录里有对应的图片文件
- Obsidian 里能正常显示图片
- 图片内容跟描述对得上

## 注意事项

::: tip
配图描述写具体点。别光写"配图:猫",写"配图:一只橘猫趴在笔记本电脑键盘上,慵懒的样子,卡通风格"。越具体出图越准。
:::

::: warning
Obsidian vault 最好用 Git 备份。AI 改文件是不可逆的,万一改崩了能回退。
:::

## 我的经验

我固定用一套"配图标记语法",比如 `<!-- img: 风格 | 描述 -->`。这样 AI 解析起来稳定,我也好维护。

还有,我会让 AI 顺便给图片起个好文件名(比如 `system-arch-20260812.png`),别让它生成一堆 `image1.png` `image2.png`,后期找图想死。
