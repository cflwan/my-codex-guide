# 用飞书 CLI 处理协作数据

## 这案例干啥的

就是让 Codex 通过飞书 CLI 去读写飞书文档、多维表格、消息之类的。比如"把上周的会议纪要整理一下,发到项目群里",它就能干。

相当于让 AI 当你的飞书小助手。

## 啥时候用

- 每周整理会议纪要,手动复制粘贴太累
- 多维表格数据要批量处理,Excel 操作费劲
- 想自动往群里发通知或报告
- 跨多个飞书文档汇总信息

## 准备工作

- 飞书 CLI 装好,登录认证通过
- Codex 能调用飞书 CLI
- 知道你要操作的文档/表格 ID 或者链接
- 有权限访问对应的飞书空间

## 怎么搞

### 第一步:确认 CLI 能用

终端里敲 `feishu --version`(或者你装的 CLI 名字),能出版本号说明装好了。

### 第二步:告诉 Codex 干啥

比如整理会议纪要:

> 帮我从飞书文档(链接:https://xxx.feishu.cn/docx/xxxx)里读取这周的会议纪要,按"决议事项""待办""讨论要点"三类整理成 markdown,然后通过飞书机器人发到"项目周报"群里。

### 第三步:AI 调用 CLI

Codex 会:
1. 用 CLI 读取文档内容
2. 用 AI 能力整理分类
3. 用 CLI 发消息到群

### 第四步:看结果

去飞书群里看消息发出去没,内容对不对。

### 第五步:存成脚本

如果是每周都干的活,跟 AI 说:

> 把这个流程写成一个脚本,我以后每周一跑一下就行。

## 验证结果

- 飞书群里收到了消息
- 文档内容读取正确,没乱码
- 整理后的格式符合预期
- 多维表格数据如果有修改,去飞书里看改没改

## 注意事项

::: tip
飞书 API 有频率限制,别短时间内疯狂调用。批量操作时加个 sleep,慢点但稳。
:::

::: warning
涉及删除文档、清空表格这类操作,务必先在测试环境试,或者先备份。AI 手滑删错数据的事儿不是没有。
:::

## 我的经验

我每周固定让 AI 干一件事:扫描多个项目群的会议纪要,提取出"涉及我名字的待办",汇总成一条消息发给我自己。省得我一个个群翻过去看。

还有,飞书多维表格批量写入时,先让 AI 写个"试运行"模式,只打印不真写,确认数据没问题再开真写。
